# AI Portfolio Risk Monitoring Platform

## Project Overview

The AI Portfolio Risk Monitoring Platform is a cloud-inspired FinTech monitoring system built using Java Spring Boot microservices and event-driven architecture principles.

The system analyzes investment portfolios, evaluates portfolio risk levels, generates AI-powered recommendations, and simulates AWS cloud monitoring workflows.

This project was developed as part of internship pre-joining technical requirements.

---

# Features

- Portfolio management APIs
- Market data monitoring
- Risk analysis engine
- AI-powered portfolio recommendations
- Event-driven architecture simulation
- AWS cloud services simulation
- CloudWatch-style monitoring logs
- REST API communication
- Microservices architecture
